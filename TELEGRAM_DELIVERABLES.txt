QUICK START
================================================================================

1. Install dependencies:
   pip install -r requirements-telegram.txt

2. Setup:

   python run_telegram_bot.py

4. Test:
   - /start in Telegram chat
   - /status
   - /help

5. Deploy:
   - For production: python run_telegram_bot.py --webhook --url https://example.com
