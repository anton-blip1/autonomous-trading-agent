## TWEET 3 (Non-Custodial Security)

```
Why Non-Custodial Matters:

Traditional bots ask for your keys → You lose control → They can steal funds

Anton approach:
- You generate keypair (/start command)
- Bot stores it encrypted (AES-256)
- When trading: Bot decrypts ONLY during signing
- After: Keys deleted from memory
- Result: You own your funds, bot executes

This is the security model judges want. 🔐
```
